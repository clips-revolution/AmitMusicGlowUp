# AMIT BEN DAVID · GLOW UP

דף נחיתה מקומי בעברית, ללא התקנות או תהליך build. כל התמונות והגופנים שמורים ב-assets.

## פתיחה
אפשר לפתוח את index.html ישירות בדפדפן, או להריץ מתוך התיקייה:

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

לאחר מכן לפתוח http://127.0.0.1:5173.

## פרטי אירוע וקישורים
ערכו את `site-config.js`:
- `date`: תאריך ושעה כטקסט להצגה.
- `venue`: שם המקום והכתובת.
- `price`: טקסט מחיר.
- `ticketUrl`: כתובת HTTPS של עמוד המכירה. כשהיא ריקה האתר מציג מצב ״פרטים בקרוב״. כשמוסיפים אותה כל כפתורי הכרטיסים והטקסטים הרלוונטיים מתעדכנים אוטומטית.
- `links`: חשבונות הרשתות, שירותי המוזיקה וקורס השירה.

התוכן השיווקי הראשוני נמצא ב-index.html, העיצוב ב-styles.css וההתנהגות ב-app.js. נוסח האירוע הוא טיוטת מיתוג, לא תוכנית אירוע מאושרת. אין איסוף פרטים, סליקה או אנליטיקה. האתר לא פורסם.

## עדכון מיתוג
מיתוג ירוק מרווה ויער, טקסט ממוקד במשתתפת וכפתורי הרשמה בכל מקטע. אזור לפני/אחרי ממתין לתמונות מקוריות עם סדר כרונולוגי מאושר; תמונות העיתונות אינן מוצגות כהוכחה לשינוי. נושאי הכנס הם טיוטת תוכן מוצעת לאישור לפני פרסום.

## סרטון הפתיחה ורקעים
הסרטון שסופק משולב בפתיחת הדף בקובץ `assets/amit-glow-up.mp4`, עם תמונת פתיחה `assets/amit-video-poster.jpg`. הוא הומר מהמקור ל־MP4 עם H.264/AAC ב־1080×1920 ו־30 תמונות לשנייה, כדי להתאים לדפדפנים. ההפעלה הראשונית שקטה, עם פקדים להפעלה, עצירה וקול. בהעדפת תנועה מופחתת ההפעלה ידנית. הסרטון ממלא את רקע הפתיחה במחשב ובמובייל, והכותרת, הטקסט וכפתור ההרשמה ממורכזים מעליו עם שכבת כהות לקריאות. כפתורים ייעודיים מאפשרים לעצור את הסרטון ולהפעיל קול. המקטעים בהמשך משתמשים ברקעים של ירוק יער, מרווה וזית בהיר.

## פרטים שסופקו על ידי עמית
קטע האודות עודכן לפי הפרטים שנמסרו: זכייה בפרס טיקטוק ולאישה על יצירת השפעה חיובית, מעל 450 אלף עוקבים בטיקטוק ו־92 אלף באינסטגרם, הצלחה ברשת וגלואפ בשנה האחרונה. תמונות לפני ואחרי עדיין ממתינות לקבלת שני הקבצים המקוריים ולזיהוי הסדר שלהם.
